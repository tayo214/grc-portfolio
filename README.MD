## Featured Work

### 🔧 SCP Guardrails → Reduced Recurring Audit Findings
Designed and implemented AWS Service Control Policies across a multi-account environment to enforce least-privilege and prevent high-risk configurations at the organizational level. Mapped each SCP to NIST 800-53 controls and used them as preventive evidence in SOC 2 and FedRAMP audits — directly reducing recurring findings across consecutive audit cycles.
→ [View artifact](./aws/scp-guardrails.md)

### ⚙️ Security Hub Finding Automation → Faster Evidence, Less Manual Work
Built a workflow to automate AWS Security Hub finding triage, normalize severity scoring, and export audit-ready evidence. Reduced the manual effort of monthly ConMon scan reconciliation and gave auditors consistently formatted, timestamped evidence packages.
→ [View artifact](./aws/securityhub-automation.md)

### 📋 FedRAMP POA&M Sample → Audit-Grade ConMon Artifact
A sanitized, realistic POA&M demonstrating how I track open findings through the full lifecycle: discovery, risk rating, remediation planning, aging logic, and Deviation Request documentation. Built to reflect actual FedRAMP Moderate ConMon practice, not just a template.
