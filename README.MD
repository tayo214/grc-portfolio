## About This Portfolio

This portfolio documents my hands-on work in governance, risk, and compliance — built from real experience operating AWS security controls in a regulated cloud environment and extended into structured GRC artifacts that reflect how mature compliance programs actually function.

My background is in cloud security engineering, where the daily work involves enforcing compliance standards across AWS services, gathering audit evidence, and working alongside security leadership on risk processes. This portfolio translates that operational experience into the language and deliverables of a dedicated GRC function: controls mapping, vendor risk assessment, security questionnaire response, continuous monitoring runbooks, and AI-assisted compliance workflows.

The artifacts here are built against frameworks and tools that appear consistently in modern GRC programs — SOC 2 Trust Service Criteria, CIS AWS Foundations Benchmark, NIST CSF, and platforms like Vanta and Drata. Each one is designed to reflect work product quality, not just conceptual understanding.

## Artifacts

### 1. SOC 2 Controls Mapping
Maps existing AWS security controls — drawn from the CIS AWS Foundations Benchmark and AWS Foundational Security Best Practices — to the SOC 2 Trust Service Criteria. This artifact reflects the kind of controls rationalization work required when maturing a compliance program or preparing for an audit.

### 2. Security Questionnaire Response
A completed sample SIG Lite questionnaire demonstrating how I would handle inbound customer security assurance requests. Security questionnaires are a high-volume, high-stakes function in any customer-facing compliance program, and this artifact shows I can manage them accurately and efficiently.

### 3. Vendor Risk Assessment Template
A structured intake and scoring template for third-party vendor assessments. Includes risk tiering criteria, control domains, and a scoring rubric aligned to common vendor risk frameworks. Built to support a scalable, repeatable vendor risk program.

### 4. AWS SOC 2 Continuous Monitoring Runbook
An operational runbook documenting how AWS-native tools — Security Hub, CloudTrail, GuardDuty, Inspector, and Config — can be used to maintain continuous controls monitoring aligned to SOC 2 requirements. Written from direct experience operating these tools in a production AWS environment.

### 5. AI-Assisted GRC Workflow
A documented workflow demonstrating how AI tools can be used to accelerate common GRC tasks: drafting questionnaire responses, mapping controls across frameworks, and generating audit evidence summaries. Practical and relevant to compliance programs focused on reducing manual overhead.
